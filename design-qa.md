# Design QA

Final result: passed

- Switch picker is anchored directly against the left edge of the event side panel with a measured zero-pixel gap.
- Picker and side panel use the same background color.
- Header, search row, and switch items reach the picker edges without outer padding.
- Search filters switches by name and identifier.
- Switch items display names only, and the selected item uses a low-opacity primary background.
- Header create and close actions use small icon buttons with tooltips.
- The creation panel opens directly against the left edge of the picker without overlap.
- The close action dismisses the picker and its nested creation panel.
- Creating a switch selects it immediately in the condition.
- Empty condition and fixed autonomous movement sections add no content spacing.
- Visual comparison completed against the two supplied reference screenshots.
